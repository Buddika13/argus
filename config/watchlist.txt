# Scope: this is a study of public caching DNS resolvers in SRI LANKA, so the
# majority of the watch-list is Sri Lankan infrastructure whose compromise would
# affect Sri Lankan users. A smaller international set is kept deliberately, for
# two reasons: it exercises delegation through many different top-level domains,
# and it provides a control group — if a resolver misbehaves only on .lk names,
# that is a materially different finding from misbehaving everywhere.
#
# Every domain below was checked against the authoritative hierarchy AND against
# all five control resolvers before inclusion. Candidates that diverged, or whose
# delegation could not be walked, are listed at the foot of this file with the
# reason, rather than silently dropped.
