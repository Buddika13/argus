# Argus Documentation

Project documentation, in a suggested reading order.

1. **[MECHANISM.md](MECHANISM.md)** — how the detection works: the two lookups,
   the set comparison, the verdicts, and the GeoDNS discriminator. Start here to
   understand *what* Argus does and *why* it is correct.

2. **[DESIGN.md](DESIGN.md)** — architecture, module responsibilities, and the
   key design decisions with their reasoning. The engineering view.

3. **[RUNNING.md](RUNNING.md)** — setup and every command, including the lab
   attacker and the optional Grafana stack. The practical guide.

4. **[OUTPUT.md](OUTPUT.md)** — real captured output from each command, including
   the attack-detection demo. What success looks like.

5. **[ROADMAP.md](ROADMAP.md)** — the six phases with per-item status, plus the
   suggested next steps.

See also the top-level [README](../README.md) for the project overview.
